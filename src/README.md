
# Banking Transaction Processing System

A Java-based banking transaction processing system
designed to handle concurrent financial transactions
with consistency, reliability and auditability.

## Technology Stack

- Java 17
- PostgreSQL 19
- JDBC
- HikariCP
- Maven
- JUnit 5
- SLF4J and Logback

## Core Features

- Deposit
- Withdrawal
- Fund Transfer
- Concurrent Transaction Processing
- Transaction Idempotency
- Database Locking
- Audit Logging
- Transaction Recovery
- SQL Reporting
- Performance Benchmarking

## Database

Database Name: banking_transaction
